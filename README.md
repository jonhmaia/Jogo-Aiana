
**Aianá - A Revolta das Lendas**
Descubra os encantos da floresta com esse mundo mágico inspirado nas lendas do folclore brasileiro. Aianá é um jogo de aventura RPG com camera top-down e uma arte cativante no estilo pixel art. Nessa aventura você vai experenciar o combate em tempo real em curta e longa distância, explorar o mapa e encontrar inimigos desafiadores, derrotar os chefes e melhorar seu personagem. Tudo isso enquanto conhece um pouco mais sobre a história desse mundo.

Para instalar o jogo, primeiro faça o download do arquivo compactado.

Extraia o arquivo aianá-v1.2.0.zip

Dentro da pasta extraída terá um executável para Windows: Aianá.exe

Basta clicar duas vezes com o mouse para executar
E o executável para Linux: Aianá.x86_64

Basta clicar duas vezes com o mouse para executar
